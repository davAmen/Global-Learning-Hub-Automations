## Session Content

### 1. Section 1: Form/Note/Table Completion

**Format:** Conversation between 2 people (social context) — booking, registration, enquiry

**Question Types:**
- Form completion (name, address, phone, dates, preferences)
- Note completion (short phrases, key details)
- Table completion (categories, prices, times)

**Key Strategies:**

| Strategy | How to Apply |
|----------|--------------|
| **Predict answers** | Read questions before audio; guess word type (number, date, name, place) |
| **Listen for signposts** | "Let me check...", "Could you spell...", "Did you say..." |
| **Watch for corrections** | "Actually...", "Sorry, I meant...", "Let me change that" |
| **Number/date formats** | Write numbers as digits; dates as "15 October" or "15/10" |
| **Spelling names** | Listen for letter-by-letter spelling; note double letters |

**Common Traps:**
- Speaker gives info, then corrects it → write the CORRECTED version
- Multiple numbers given (price, phone, date) → match to question
- Synonyms used in audio vs question (e.g., "cost" → "price")

### 2. Section 2: Multiple Choice & Matching

**Format:** Monologue (1 speaker) on social topic — tour, facility, event

**Question Types:**
- Multiple choice (A/B/C) — single or multiple answers
- Matching (features to options, speakers to opinions)
- Map/plan/diagram labeling (less common in Section 2)

**Key Strategies:**

| Strategy | How to Apply |
|----------|--------------|
| **Read all options first** | Underline keywords; predict synonyms |
| **Eliminate wrong answers** | Cross out clearly wrong options as you listen |
| **Listen for signposting** | "First...", "Another point...", "Finally..." |
| **Watch for "not" / "except"** | Negative questions flip the answer |
| **Don't leave blanks** | Guess if unsure — no penalty for wrong answers |

**Matching Strategy:**
1. Read all options first (A-H)
2. Listen for keywords matching each option
3. Cross off used options
4. If unsure, use process of elimination

### 3. Practice Session: Cambridge IELTS 14, Test 1

**Materials:** Cambridge IELTS 14, Test 1 (Sections 1-2)

**Procedure:**
1. Pre-listening: 2 minutes to read all questions
2. Play audio (Sections 1-2, ~20 minutes)
3. Transfer answers (2 minutes)
5. Mark using answer key
6. Review every wrong answer — identify trap type

**Answer Key Highlights:**
- Q1: "15 October" (date format)
- Q3: "2 adults, 1 child" (correction: speaker says "2 adults" then "actually 3 adults")
- Q8: B (speaker says "not recommended" = not A or C)
- Q12: E & F (matching — both mentioned as features)

## Key Vocabulary for This Session

| Term | Definition | Example |
|------|------------|---------|
| **Distractor** | Incorrect info designed to mislead | "The price is $20... actually $25" |
| **Signpost** | Words signaling structure | "First...", "Moving on to..." |
| **Paraphrase** | Same meaning, different words | "cost" → "price" / "fee" |
