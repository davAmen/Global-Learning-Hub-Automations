## Learning Outcomes

By the end of this course, students will be able to:

1. **Listening**: Identify key information in all 4 sections; predict answers; manage time across 40 questions
2. **Reading**: Skim/scan effectively; answer all 14 question types; complete 40 questions in 60 minutes
3. **Writing Task 1**: Describe charts, graphs, maps, processes in 150+ words with appropriate vocabulary
4. **Writing Task 2**: Write 250+ word essays with clear position, developed arguments, cohesive devices
5. **Speaking**: Respond fluently in all 3 parts; use lexical resource; demonstrate grammatical range
